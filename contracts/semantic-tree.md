# 语义命名树合同

## 1. 层级与 ID 规则

```text
PARK-01                     园区（单园区演示，预留多园区）
├── BLDG-B01 … B06          楼栋（厂房A/B/C、办公楼、宿舍食堂、配电房）
│   └── RF-B01 …            屋顶（每栋楼一个屋顶对象，含朝向/倾角/可用率）
│       └── PV-B01-A        屋顶子阵（一个屋顶一个子阵）
│           ├── INV-A-01 …  组串式逆变器（挂在所属子阵下）
│           │   └── STR-A-01-01 …  组串（INV 内编号）
│           └── JBOX-B01    并网箱
├── PV-P01-A                光伏车棚子阵（车棚与楼栋同级）
├── ESS-01                  储能系统（含 2 台储能柜 ESS-01-C1/C2）
├── EV-01 … EV-04           充电桩
├── TR-01                   箱变（2×1000kVA）
├── MT-01                   园区总电表（并网点）
├── WS-01                   环境监测仪
└── OPS-01                  运维点（小人出发点）
```

规则：

- ID 全大写，连字符分段；层级不得跳跃（组串必须挂在逆变器下）。
- 任何告警、任务、证据、报告、UI 信息卡必须用上述 ID 引用对象。
- 新增设备类型须先在本文件登记类型码与挂载层级。

## 2. 设备类型与语义卡字段

每类设备的信息卡（UI 点击弹出）至少包含：

| 类型 | 必填字段 |
|---|---|
| 屋顶子阵 PV | 装机容量 kWp、组件数、朝向/倾角、投运日期、今日实发/应发、自用比例 |
| 逆变器 INV | 型号（华为 SUN2000 系列）、额定功率、组串数、效率、今日发电量、状态 |
| 组串 STR | 电流/电压（演示期 SIMULATED）、偏差率、所属逆变器 |
| 储能 ESS | 额定功率/容量、SOC、今日充/放电量、当前策略模式 |
| 充电桩 EV | 功率、状态（空闲/充电中）、今日充电量 |
| 箱变 TR | 容量、负载率、最大需量（当月） |
| 电表 MT | 正向/反向电量（购电/上网）、峰平谷分项 |
| 气象仪 WS | 辐照、温度（数据源标签） |

## 3. 状态机

### 设备状态

`normal（正常）/ degraded（性能偏低）/ fault（故障）/ offline（离线）/ maintenance（检修中）`

### 巡检任务状态

```text
created（已生成）→ dispatched（已派发）→ enroute（前往中）
→ onsite（到场）→ inspecting（检查中）→ evidence-submitted（证据已提交）
→ resolved（已消缺）/ escalated（升级处理）
```

- 每次状态迁移必须记录时间、操作人（演示期为模拟操作人）、关联证据 ID。
- 任务关闭后，关联子阵的发电曲线必须在下一个数据周期体现恢复（闭环验证）。
